WHAT CHANGES BETWEEN VARIANTS?

Same evidence. Different smoothing.

The raw baseline selects the tracked player closest to the ball. A centred majority window reduces flicker. Missing ball observations are treated as dead play by the raw baseline—an important limitation.

A smoother timeline is not necessarily more accurate. Real short possessions can disappear.

REPRODUCIBILITY FIRST

One Python project. No cloud required.

Recreate the website

Use Python 3.11 or newer. From the project folder:

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m controlswitch serve

Open http://127.0.0.1:8765. This starts an entirely synthetic walkthrough.

Reproduce a licensed match run

Obtain the organiser’s data separately, then point the pipeline at its parent folder:

python -m controlswitch baseline \
  --data-root "/path/to/dataset" \
  --out work/runs/baseline-001

python -m controlswitch serve \
  --run-dir work/runs/baseline-001

The loader discovers the split tactical files recursively. Original downloads stay untouched.

What this version does not establish

The synthetic walkthrough is not a trained-model evaluation. External model results are in the separate reports. No competition ground truth or video is used for training, tuning or prediction checks. Restricted inputs and generated match timelines stay local.
