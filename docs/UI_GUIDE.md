# Match centre

Open the Mac launcher or dashboard.html. Both start with the named external example; the unnamed synthetic demo has been removed. Everything works offline; provided-match inputs and predictions stay local.

- **Match:** the team-control split, possession intervals and match summary.
- **Players:** named external player estimates or anonymous challenge tracks, team selector, search and CSV export. Search preserves the unassigned row and the full-team denominator; it does not renormalise visible rows into misleading percentages.
- **Model evidence:** the frozen fresh-match comparison, previous external results and plain-language limitations. Spell F1 is not percentage match accuracy.
- **Reset named demo:** returns from a private/imported analysis to the named external example.
- **Open local analysis:** reads a JSON/CSV in the browser without uploading it.

The dark design uses blue/claret panels, gold accents, a custom PL shield, a Catalan-colour detail and a schematic pitch. It is independently Barcelona-inspired, without the official club crest or a claim of affiliation. Cards prioritise the possession split; tabs support keyboard arrows, Home and End. Focus outlines, reduced-motion support and small-screen layouts are included. Player identity limitations remain visible.

Verification: data/schema/interaction calculations and offline packaging are checked automatically. Visual browser QA could not be completed in this environment: the in-app browser blocked the file protocol. This is a verification limit, not a claim that every screen size was visually tested.

## Named match library (12 November)

Choose a match in the new library selector. All nine historical SkillCorner matches and Bochum–Leverkusen are bundled offline. Each selection updates team percentages, timeline and named-player impact estimates. The Players tab shows only roster-mapped people; anonymous track rows are hidden, including when an imported local analysis lacks a permitted mapping. Search and named-player CSV export work for the selected team. Unresolved control is shown separately and stays in the percentage denominator.

Impact is estimated proximity involvement and associated bouts, not confirmed contacts, passes or causal attacking value. Provider identities are automatically joined, not manually verified. Across these examples, mapped control covers roughly 34–59% of each team's model control. The H/A-only examples mark stopped play as “Not classified”; the timeline uses concatenated tracking-period time, not a broadcast video clock. No raw organiser data is bundled.

Model evidence now shows the fixed 2841 context-RNN comparison, including the conditional-label limitation and unmet 0.8 target. Match library examples include development matches and viewed tests; they do not supply ten independent model evaluations.

Validation: payload checks, named/anonymous ledger tests, all ten match switches, both teams, search and unsupported dead-ball display were tested. Layout/browser visual QA remains unverified in this environment; no local-file security restriction was bypassed.
