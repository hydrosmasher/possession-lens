# Anonymous top-five-league tracking recheck — 14 November2026

A focused recheck did not verify an additional licensed, anonymously downloadable top-five first-division match with continuous tracking and usable frame-level H/A/D supervision. This is a bounded search result, not proof no other dataset exists.

- Driblab's README describes ten European tracking matches, but the observed main-branch root lists images, .gitattributes and README only. The claimed dataset directory, a usable possession-label specification and a data licence were not verified. No files imported or used.
- PathCRF is a relevant possession/event model with MPL2.0 source, but its README uses the same seven-match Sportec/DFL release already audited here. It supplies synchronized event derivatives, not newly independent games. Only two of the original seven games qualify as first-division Bundesliga; importing another representation does not create a fresh test. No code, weights or annotations imported.
- Current SkillCorner main README describes A-League examples, outside the user's league restriction. The historical nine-match European release remains fully viewed and none is relabelled fresh.
- Event-only releases and discrete freeze frames do not establish continuous possession supervision. Gated/login-required sources remain excluded under the user's explicit anonymous-only preference.
