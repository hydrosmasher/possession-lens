# One project, one match centre

Start from the root launcher or `dashboard.html`. Technical research files live here in docs/research; their earlier commands and paths are historical. External score reports live in reports/external. Old standalone technical pages are archived under reports/archive rather than presented as separate judge interfaces.

The provided dataset retains its original assets and relative links under data/raw so alignment and provenance are preserved. External match caches are grouped under data/external/cache. Training run history remains private. The UI never uploads input files, performs fitting or checks predictions against video.

The Git repository and GitHub Desktop should both point to the Desktop/Possession Lens working folder. The previous GitHub clone and pre-cleanup folder are retained separately as backups, not active working copies.
