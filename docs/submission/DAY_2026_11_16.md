# Smart-tag audit and episode evidence —16 November2026

## What was checked

The organiser's current DATA/RULES/SUBMISSION documentation was reviewed. Smart Tagging is automatic SportsCode phase/set-piece evidence on the tactical video clock, not possession truth or exact touch/restart times. A local schema/range audit passed without inspecting the video or comparing tags against model predictions or possession labels. Raw tags and their intervals remain private. The source parser handles case differences, documented team spelling, unknown teams, conflicting votes and half-open frame intervals; set-piece windows are never converted wholesale into dead-ball labels.

## Bounded external pilot

Both existing first-division Bundesliga matches have synchronised provider events. The missing WMX event/metadata files were obtained anonymously from the pinned CC BY4.0 IDSSE mirror. Event timestamps were aligned using tracking N/T only, with a25Hz consistency check. No BallStatus/BallPossession reference fields were used to construct phase evidence.

Phase windows group first/last provider actions by provider phase and team, with fixed one-second padding. The episode rule can only veto an existing070short recovery when every episode frame has unopposed opposite-team evidence. Unknown/conflicting/partial cues abstain. The rule and a30%dropout/10%wrong-team/±2second jitter corruption test were fixed before scoring. No challenge data enters the external experiment.

**Transfer is not established.** Provider event phases are stronger/different annotations than Metrica automatic tags and may share annotation ancestry with the external reference. The pilot is not a measured model of Metrica errors, and the same two matches have been extensively reused. It does not justify a claim of challenge improvement.
